# GNISLS

Main Examples
SimEMT_Noiseless_Github.py – Generates noiseless simulated data and performs network inference. No smoothing is applied since no noise is added.
SimEMT_Noisy_Github.py – Generates noisy simulated data with smoothing, and performs network inference.
Both scripts can be run directly after download to generate simulated time-series data and infer the underlying network.

Supplementary Script
SimEMT_Jacobi_Github.py – Compares the inferred network with the Jacobian matrix of the simulated system. This is provided as an optional supplementary result for reference.
